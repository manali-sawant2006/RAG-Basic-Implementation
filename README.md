
# RAG - Basic Implementation

## About
This repository contains my basic hands-on implementation of Retrieval-Augmented Generation (RAG) using Python, LangChain and Groq.

## What is RAG?
Retrieval-Augmented Generation (RAG) combines information retrieval with a Large Language Model (LLM) to generate answers using relevant external knowledge.

## RAG Workflow
1. Document Loading
2. Text Chunking
3. Embeddings Generation
4. Vector Database Storage
5. Document Retrieval
6. Context and Prompt Creation
7. LLM Response Generation

## Technologies Used
- Python
- LangChain
- Groq API
- Sentence Transformers
- Vector Database

## Learning Outcomes
- Understood the basic RAG architecture.
- Learned how document retrieval works.
- Explored embeddings and context creation.
- Implemented basic LLM-based answer generation.

## How to Run
1. Clone this repository.
2. Install the required dependencies.
3. Configure your Groq API key.
4. Open the Jupyter Notebook.
5. Execute the notebook cells sequentially.

## Note
This is a beginner-level hands-on implementation for learning the fundamentals of RAG.
